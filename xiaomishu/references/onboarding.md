# 入门问卷

原则：
- **全部用选择题**（AskUserQuestion），每批最多 4 题，每题 2–4 个选项，「其他」会自动出现，让他想补充就补充。
- 多选题用 `multiSelect: true`。
- 每轮之间说一句轻松的话，比如「第一轮搞定，还有两轮」。
- 他说「跳过」就跳过，不解释为什么要问。
- 每轮结束立刻把答案写进记忆，一条一行，标注 [stated]。
- 选项按下面的写，可以根据前面的回答微调（比如他说没养宠物，就不问宠物）。

## 第一轮：基本节奏（4 + 4 题）

批次 A
1. 怎么称呼你？——（选项：用名字 / 用外号 / 叫「老板」 / 其他）→ 选了名字或外号，追问一句具体叫什么（这是唯一一道需要打字的题）。
2. 你一般几点起床？——7 点前 / 7–8 点 / 8–9 点 / 9 点以后
3. 一般几点睡？——11 点前 / 11–12 点 / 12–1 点 / 1 点以后
4. 工作是什么样的？——固定上班 / 混合办公（有的天去公司） / 全远程 / 学生或其他

批次 B
5. 一周哪几天去公司？（多选）——周一 / 周二 / 周三 / 周四（「其他」里可写周五或不固定）
6. 下班一般几点到家？——5 点前 / 5–6 点 / 6–7 点 / 7 点以后
7. 家里有谁？（多选）——另一半 / 宠物 / 孩子 / 就我自己
8. 你希望小秘书主要帮你管什么？（多选）——每天日程 / 待办和购物清单 / 生活里定期要做的事（理发、体检…） / 长期项目和学习

## 第二轮：生活细节（4 + 4 题）

批次 C
1. 有没有定期要做、但老是忘的事？（多选）——理发 / 看牙或体检 / 给家人打电话 / 交账单、查账
2. 吃饭怎么安排？——自己做为主 / 外卖或外食为主 / 一半一半 / 不太规律
3. 运动呢？——固定在练 / 想开始但没开始 / 偶尔 / 不运动
4. 周末一般怎么过？——宅家 / 出门玩 / 做家务、办事 / 看心情

批次 D
5. 有没有正在做的长期项目或想学的东西？——有，好几个 / 有一个 / 想有但还没开始 / 没有（有的话追问名字，可以下一轮再细问）
6. 有什么特别讨厌、不想被安排的事？——太早的安排 / 一天排太满 / 社交活动 / 没有特别的
7. 有没有饮食上的忌口？——有（追问） / 没有
8. 你的生日？——（让他选「告诉你」再输入，或「先不说」）

## 第三轮：小秘书的风格（4 题）

1. 小秘书说话的风格？——简短干脆 / 温柔一点 / 活泼爱开玩笑 / 像同事一样正式
2. 多主动？——每天早晚都来找我 / 只在有事时找我 / 每天早上一次就够 / 我需要时再叫你
3. 我拖延的时候？——直接催我 / 温和提醒一次 / 别催，帮我重新排 / 看情况
4. 早上提醒几点？晚上预告几点？——（早上给 3 个按他起床时间算的选项；晚上给 3 个按睡觉时间往前 1.5–2 小时的选项）

问完后：复述 5–8 条关键点（称呼、作息、上班日、要管什么、风格），让他纠正，再写进记忆。

## 之后「慢慢问」题库（每天最多一题）

挑和当天话题相关的问，问得自然，不要像填表。例子：
- 你最喜欢的一家餐厅是？
- 最近有什么想买但还没买的？
- 有没有一直想去的地方？
- 压力大的时候，什么能让你放松？
- 有什么小事会让你一整天心情好？
- 有没有想养成的习惯？
- 家人朋友里，有谁的生日你不想错过？
- 有没有一件拖了很久、想找人推一把的事？
